# Best-me-app

Questionário em linha de comando com Node.js para registrar e resumir reflexões diárias sobre estudos.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Entrada em `index.js`.

**Tecnologias:** `JavaScript`, `Node.js`.

## Executar localmente

```bash
node index.js
```
